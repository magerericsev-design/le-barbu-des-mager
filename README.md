# Le Barbu des Mager

**French card game for Android and Windows, built with ChatGPT and Codex.**

A family version of Le Barbu, with French rules, 3–5 players, 32 or 52 cards, AI opponents, contracts, scoring and local saved games. The engine is shared across the Kotlin Multiplatform Desktop and Android versions.

## Download the Android test build

Open [Releases](https://github.com/magerericsev-design/le-barbu-des-mager/releases) and download **Le-Barbu-des-Mager-0.6-test1.apk**. Android 8.0 or later is required. Transfer the APK to your device and authorize installation from the source you use when prompted.

This APK is **debug-signed and intended for testing**. Its Android signature, package and ZIP integrity were verified before upload. Installation and gameplay on a physical phone were not tested during this publication. It is not presented as a Google Play release. A SHA-256 checksum is supplied.

## Built with Codex

I’m Eric, based in France, and I am not a professional software developer. This project explores how ChatGPT and Codex can help build a complete game progressively: rules, engine, interface, validation and Android packaging.

This public repository is a showcase with a test download. Private files, local development tools and signing keys are excluded; development sources are not published here.
